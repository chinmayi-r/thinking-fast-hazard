How this works

You are the brain. Each time the robot finishes an action it asks you for the next one. Time does not pass while you think: the fire only spreads while the robot is doing something.

You get exactly the text the language model gets, nothing more. Distances are in metres from the robot. Temperatures are the object's; things lose value once they burn.

What you choose

  • Go pick up object X sends the robot walking toward X. Picking up is automatic: when the robot arrives next to a target it picks it up by itself, and when it is holding one it puts it in its bag by itself. You never choose those; the model does not either.
  • Look around turns the robot a full circle. Only objects it has seen are ever listed, so this is how new targets appear.

What goes wrong, and how you will know

  • A walk ends when the robot is within half a metre of the object or after 100 steps, whichever comes first. 100 steps is about 3 seconds of fire. If it did not get there, the history line will say paused after taking 100 steps, and you can send it again from where it stopped.
  • The robot cannot pick up something it is not standing next to, so a walk that stops short saves nothing.
  • The lists are only as fresh as the robot's last look. An object "previously seen" may have moved out of view or caught fire since.

Score

Value saved divided by value in the room. Valuable categories count 5, the rest 1; a burning or burnt object counts half. The episode ends at frame 1500, 50 seconds of fire.
